# 概要
パンをふっくらさせる小麦粉改良剤。動物実験で腎臓腫瘍などが報告されている。

# 発がん性に関する根拠
IARCは1999年（第73巻）に臭素酸カリウムをグループ2Bに分類した。ラットで腎臓・甲状腺などの腫瘍が報告されている。

# 日本での扱い
日本ではパン製造用の小麦粉に限り、臭素酸として0.030g/kg以下、最終食品の完成前に分解または除去することを条件に使用が認められている。多くの大手メーカーは使用を中止している。

# 気をつけること
表示がある場合は使用基準どおり除去されている前提だが、気になる場合は不使用製品を選ぶ。
