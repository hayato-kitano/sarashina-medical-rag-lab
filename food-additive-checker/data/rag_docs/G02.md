# 概要
日本の食品表示基準では、原材料名欄で原材料と添加物を「/」記号・改行・別欄などで区分して表示する。

# 詳しい説明
添加物は重量の多い順に表示される。「発色剤（亜硝酸Na）」のように用途名と物質名を併記するものや、「香料」「乳化剤」「pH調整剤」のような一括名で表示され具体的な物質が分からないものがある。加工助剤やキャリーオーバーは表示が免除される場合がある。

# 日本での状況
食品表示法・食品表示基準に基づく。

# 注意
一括名表示の添加物は個別物質を特定できないため、この診断の対象外になることがある。
