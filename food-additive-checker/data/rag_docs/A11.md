# 概要
海藻由来の増粘剤。食品用とは別物の低分子化した「分解カラギーナン（ポリギーナン）」に発がん性の懸念がある。

# 発がん性に関する根拠
IARCは食品用（未分解）カラギーナンをグループ3、分解カラギーナンをグループ2Bに分類している。分解カラギーナンは食品添加物として使用が認められていない。

# 日本での扱い
日本では既存添加物として使用が認められている。増粘多糖類と一括表示されることもある。

# 気をつけること
食品用カラギーナンでヒトの発がん性は示されていない。
