# 概要
清涼飲料・菓子などの赤色合成着色料。米国では発がん性を否定できないとして1976年に食品への使用が取り消された。

# 発がん性に関する根拠
IARCは赤色2号（アマランス）をグループ3としている。米国FDAは1976年、ラット試験の結果から発がん性の疑いを否定できないとして認可を取り消した。

# 日本での扱い
日本では使用基準付きで認められている。EUでも用途を限定して認められている。

# 気をつけること
気になる場合は「赤色2号」「赤2」の表示がない製品を選ぶ。
