# 概要
菓子・漬物・かまぼこなどに使われる赤色の合成着色料。雄ラットで甲状腺腫瘍が報告され、米国で食品への使用許可が取り消された。

# 発がん性に関する根拠
米国FDAは2025年1月15日、高用量を与えた雄ラットで甲状腺がんが認められた報告を根拠に、デラニー条項に基づいて食品への使用許可を取り消した（食品は2027年1月15日までの経過措置）。一方でFDAは、この発がん機序はラット特有でヒトには起こらず、ヒトへの健康影響は科学的に裏付けられていないとしている。

# 日本での扱い
日本では昭和23年から指定されている着色料で、消費者庁が情報を公開し評価を続けている。EUでは1994年以降、カクテルチェリー等の一部を除き食品への使用が制限されている。

# 気をつけること
気になる場合は「赤色3号」「赤3」の表示がない製品を選ぶ。
