# 概要
日本で指定されている合成着色料。一部（赤色104号・105号・106号など）は米国やEUで食品に認められていない。

# 発がん性に関する根拠
これらの色素について、ヒトでの発がん性を示す確立した証拠は報告されていない。国によって認可状況が異なるのは主に評価・申請状況の違いによる。米国FDAは2025年に石油由来合成着色料の段階的な廃止方針を示した。

# 日本での扱い
日本では食品衛生法で指定され、カステラ・きなこ・生鮮食品などへの使用は禁止されている。

# 気をつけること
発がん性の懸念は限定的。気になる場合は天然色素の製品を選ぶ。
