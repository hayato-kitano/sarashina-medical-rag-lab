# 概要
食肉製品やチーズ・清酒などに使われる発色剤。体内で亜硝酸塩に変わり、ニトロソアミン生成につながりうる。

# 発がん性に関する根拠
IARCは2010年（第94巻）、体内でニトロソ化が起こる条件下で摂取された硝酸塩をグループ2Aに分類した。なお硝酸塩は野菜にも多く含まれ、野菜由来の摂取では同様の関連は示されていない。

# 日本での扱い
日本では食肉製品・鯨肉ベーコン・チーズ・清酒などに使用基準付きで認められている。

# 気をつけること
加工肉の頻繁な摂取を控える。
