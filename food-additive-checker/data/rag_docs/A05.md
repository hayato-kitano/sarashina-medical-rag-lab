# 概要
菓子のコーティング、ホワイトチョコ、ガムなどを白くする着色料。粒子（ナノ粒子を含む）の遺伝毒性が懸念されている。

# 発がん性に関する根拠
IARCは2010年（第93巻）に二酸化チタンをグループ2Bに分類したが、これは主にラットの吸入試験に基づく。EFSA（欧州食品安全機関）は2021年、遺伝毒性の懸念を否定できないとして食品添加物としての安全性を確認できないと結論し、EUは2022年に食品への使用を禁止した。

# 日本での扱い
日本では着色料として指定され、使用が認められている。

# 気をつけること
経口摂取での発がん性はヒトで確認されていない。気になる場合はE171・二酸化チタン不使用の製品を選ぶ。
