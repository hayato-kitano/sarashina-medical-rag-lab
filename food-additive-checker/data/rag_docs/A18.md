# 概要
飲料などに広く使われる高甘味度甘味料。IARCの分類対象になっておらず、発がん性は確認されていない。

# 発がん性に関する根拠
IARCではいずれも評価されていない。スクラロースについては、不純物・代謝物のスクラロース-6-アセテートが試験管内で遺伝毒性を示したとする2023年の研究があるが、ヒトでの影響は確認されていない。

# 日本での扱い
日本では使用基準付きで認められている。

# 気をつけること
現時点で発がん性を示す確立した証拠はない。
