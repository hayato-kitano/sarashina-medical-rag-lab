# 概要
コーラ、ソース、しょうゆ加工品などに使われる茶色の着色料。製法によって副生成物の4-メチルイミダゾール（4-MEI）を含む。

# 発がん性に関する根拠
アンモニウム化合物を使って製造するカラメルIII・IVには4-MEIが生じる。IARCは2012年（第101巻）に4-MEIをグループ2B（発がん性がある可能性がある）に分類した。マウスの試験で肺腫瘍の増加が報告されている。カラメルI・IIは4-MEIをほとんど含まない。

# 日本での扱い
日本では使用基準なしで使用が認められている。表示は「カラメル色素」と一括されることが多く、I〜IVのどれかは表示から分からない。

# 気をつけること
清涼飲料などで大量・毎日摂取するのを控える。
