# 概要
輸入かんきつ類（レモン・オレンジ・グレープフルーツ）の皮に使われる防かび剤。ナトリウム塩でラットの膀胱腫瘍が報告されている。

# 発がん性に関する根拠
IARCは1999年（第73巻）、オルトフェニルフェノールナトリウムをグループ2B、オルトフェニルフェノール本体をグループ3に分類した。ラットに高用量を与えた試験で膀胱腫瘍が報告されている。

# 日本での扱い
日本ではかんきつ類に使用基準付きで認められ、バラ売りでも値札などに表示される。

# 気をつけること
皮を使う場合（マーマレード、レモンピール等）はよく洗うか防かび剤不使用のものを選ぶ。
