# 概要
ダイエット飲料や菓子に使われる人工甘味料。2023年にIARCが「発がん性がある可能性がある」と分類した。

# 発がん性に関する根拠
IARCは2023年7月（第134巻）、肝細胞がんとの関連を示す限定的な証拠に基づきアスパルテームをグループ2Bに分類した。同時にJECFA（FAO/WHO合同食品添加物専門家会議）は一日摂取許容量（ADI）体重1kgあたり40mgを維持し、通常の摂取量では懸念はないとした。

# 日本での扱い
日本では使用が認められており、「アスパルテーム・L-フェニルアラニン化合物」と表示される（フェニルケトン尿症の人への注意表示）。

# 気をつけること
体重60kgの人のADIは1日2,400mgで、通常の摂取量で超えることは少ない。
