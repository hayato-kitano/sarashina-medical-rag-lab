# 概要
油脂・チューインガムなどの合成酸化防止剤。BHAとよく併用される。

# 発がん性に関する根拠
IARCはBHTをグループ3（分類できない）としている。動物実験の結果は一貫していない。

# 日本での扱い
日本では油脂、バター、魚介乾製品、チューインガムなどに使用基準付きで認められている。

# 気をつけること
現時点でヒトの発がん性を示す証拠はない。
