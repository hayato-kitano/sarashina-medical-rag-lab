# 概要
ワイン・ドライフルーツ・かんぴょうなどに使われる。発がん性よりも喘息などの過敏症状が問題になる。

# 発がん性に関する根拠
IARCは二酸化硫黄・亜硫酸塩をグループ3としている。

# 日本での扱い
日本では使用基準付きで認められている。

# 気をつけること
発がん性の懸念は低いが、喘息のある人は過敏反応に注意。
