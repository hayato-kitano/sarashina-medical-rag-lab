# 概要
かずのこ等の殺菌・漂白に使われる。最終食品に残ってはならない。

# 発がん性に関する根拠
IARCは過酸化水素をグループ3としている。マウスへの飲水投与で十二指腸腫瘍が報告されたことがある。

# 日本での扱い
日本では最終食品の完成前に分解または除去することを条件に使用が認められ、通常は表示されない。

# 気をつけること
残留しない前提のため通常は心配不要。
