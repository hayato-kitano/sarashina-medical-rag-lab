# 概要
ハム・ソーセージ・ベーコンなどの発色剤。体内や加熱時にアミン類と反応して発がん性のあるN-ニトロソ化合物（ニトロソアミン）を生成しうる。

# 発がん性に関する根拠
IARCは2010年（第94巻）、体内でニトロソ化が起こる条件下で摂取された硝酸塩・亜硝酸塩をグループ2A（おそらく発がん性がある）に分類した。また2015年（第114巻）には加工肉の摂取をグループ1（大腸がん）に分類しており、亜硝酸塩由来のN-ニトロソ化合物が要因の一つと考えられている。

# 日本での扱い
日本では食肉製品などに使用基準（食肉製品では亜硝酸根として0.070g/kg以下）が定められ、使用が認められている。ボツリヌス菌の増殖を抑える役割もある。

# 気をつけること
加工肉の食べ過ぎを避け、野菜や果物（ビタミンCはニトロソ化を抑える）と組み合わせる。
