# 概要
IARC（国際がん研究機関）の分類は「ヒトにがんを起こす可能性がある証拠の強さ」を示すもので、実際の摂取量でのリスクの大きさを示すものではない。

# 詳しい説明
グループ1はヒトに対して発がん性がある、グループ2Aはおそらく発がん性がある、グループ2Bは発がん性がある可能性がある、グループ3は分類できない、を意味する。分類はハザード（有害性の有無）の評価であり、リスク（実際の摂取量での影響）は別にJECFAや各国機関がADI（一日摂取許容量）などで評価する。

# 日本での状況
日本では食品安全委員会がリスク評価を行い、使用基準を守った食品添加物は健康への悪影響がないとされている。

# 注意
分類だけで「この食品を食べるとがんになる」と判断しないこと。
