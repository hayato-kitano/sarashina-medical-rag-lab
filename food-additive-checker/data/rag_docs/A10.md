# 概要
清涼飲料・しょうゆ・マーガリンなどの保存料。それ自体の発がん性は示されていないが、ビタミンC（アスコルビン酸）と共存すると微量のベンゼンが生じることがある。

# 発がん性に関する根拠
ベンゼンはIARCグループ1（ヒトに発がん性あり）。安息香酸塩とアスコルビン酸を含む飲料で、熱や光の条件によって微量のベンゼンが生成することが報告され、米国FDAが調査を行った。

# 日本での扱い
日本では清涼飲料水、しょうゆ、キャビア等に使用基準付きで認められている。

# 気をつけること
「安息香酸Na」と「ビタミンC」が両方表示された飲料は、高温や直射日光を避けて保存する。
