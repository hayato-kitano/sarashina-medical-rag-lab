# 概要
古くからある人工甘味料。かつてラットの膀胱がんで懸念されたが、ヒトには当てはまらない機序と判明している。

# 発がん性に関する根拠
IARCは1999年にサッカリンをグループ2Bからグループ3に変更した。ラットの膀胱腫瘍はラット特有の尿の性質による機序とされた。

# 日本での扱い
日本では使用基準付きで認められている。

# 気をつけること
現時点でヒトの発がん性を示す証拠はない。
