# 概要
油脂や魚介乾製品の酸化を防ぐ合成酸化防止剤。高用量の動物実験で前胃の腫瘍が報告されている。

# 発がん性に関する根拠
IARCはBHAをグループ2Bに分類している。ラット・ハムスターの前胃（ヒトにはない臓器）で腫瘍が報告されている。

# 日本での扱い
日本では油脂、バター、魚介乾製品などに使用基準付きで認められている。

# 気をつけること
ヒトでの発がん性は確認されていない。気になる場合は不使用製品を選ぶ。
