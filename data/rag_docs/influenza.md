# インフルエンザとは
インフルエンザは、インフルエンザウイルスによる急性の呼吸器感染症です。38℃以上の急な発熱、頭痛、関節痛、筋肉痛、全身のだるさなどの全身症状が比較的急速に現れるのが特徴で、のどの痛み、鼻水、せきも見られます。日本では例年12月から3月ごろに流行します。

# 感染経路と予防
主な感染経路は、せきやくしゃみによる飛沫感染と、ウイルスが付着した手で口や鼻に触れることによる接触感染です。予防には、流行前のワクチン接種、手洗い、せきエチケット、適度な湿度の保持、十分な休養と栄養が有効とされています。

# 治療
抗インフルエンザ薬は、発症から48時間以内に使用を開始すると、発熱期間の短縮などの効果が期待されます。使用の要否は医師が判断します。小児・未成年者では、薬の種類にかかわらず、急に走り出すなどの異常行動が報告されているため、発症後少なくとも2日間は保護者が様子を見守ることが勧められています。

# 受診の目安
呼吸が苦しい、意識がもうろうとしている、けいれんがある、水分がとれないなどの症状がある場合は、早めに医療機関を受診してください。高齢者、乳幼児、妊婦、持病のある人は重症化しやすいため注意が必要です。

# 出席停止期間
学校保健安全法施行規則では、インフルエンザ（特定鳥インフルエンザ等を除く）の出席停止期間を「発症した後5日を経過し、かつ、解熱した後2日（幼児にあっては3日）を経過するまで」と定めています。
