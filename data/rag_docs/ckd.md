# 慢性腎臓病とは
慢性腎臓病（CKD）は、腎臓の働きが徐々に低下していく状態の総称です。尿たんぱくなど腎臓の障害を示す所見、または腎臓の働きを示すeGFR（推算糸球体ろ過量）が60mL/分/1.73m²未満の状態のいずれか、または両方が3か月以上続く場合にCKDと診断されます。

# 原因と危険因子
主な原因は、糖尿病（糖尿病性腎症）、高血圧、慢性糸球体腎炎などです。加齢、肥満、喫煙、脂質異常症も危険因子になります。

# 症状
初期にはほとんど自覚症状がありません。進行すると、むくみ、倦怠感、貧血、夜間の頻尿などが現れることがあります。健康診断の尿検査や血液検査（クレアチニン、eGFR）で早期に見つけることが重要です。

# 進行を防ぐために
血圧と血糖の管理、減塩、禁煙、適正体重の維持が基本です。たんぱく質やカリウムの制限が必要かどうかは病状によって異なるため、自己判断で極端な食事制限をせず、医師や管理栄養士の指導を受けてください。市販の鎮痛薬の一部は腎臓に負担をかけることがあるため、使用前に医師や薬剤師に相談すると安心です。
