# 高血圧とは
高血圧は、血管にかかる圧力が慢性的に高い状態です。自覚症状がほとんどないまま進行し、脳卒中、心筋梗塞、心不全、慢性腎臓病などのリスクを高めることから「サイレントキラー」とも呼ばれます。

# 診断の目安
日本高血圧学会の高血圧治療ガイドライン2019では、診察室で測定した血圧が140/90mmHg以上、または家庭で測定した血圧が135/85mmHg以上の場合を高血圧としています。家庭血圧は診察室血圧より低めに出ることが多いため、基準値も低く設定されています。診断には一度の測定ではなく、複数回の測定結果が用いられます。

# 家庭血圧の測り方
家庭血圧は、朝は起床後1時間以内・排尿後・朝食前・服薬前に、夜は就寝前に、座って1〜2分安静にしてから上腕で測定するのが基本です。測定値は記録して受診時に医師に見せると、治療方針の検討に役立ちます。

# 生活習慣の改善
生活習慣の改善は、高血圧の予防と治療の基本です。
- 減塩：食塩摂取量は1日6g未満が目標とされています。
- 野菜・果物を積極的にとる（腎臓病などで制限がある人は医師に確認する）。
- 適正体重の維持、定期的な有酸素運動。
- 節酒と禁煙。
降圧薬の開始や変更、中止は医師が判断します。自己判断で服薬をやめると血圧が急に上がることがあるため、必ず医師に相談してください。
