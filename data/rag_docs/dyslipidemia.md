# 脂質異常症とは
脂質異常症は、血液中のLDLコレステロール（いわゆる悪玉コレステロール）や中性脂肪（トリグリセライド）が多すぎる、またはHDLコレステロール（いわゆる善玉コレステロール）が少なすぎる状態です。自覚症状はありませんが、動脈硬化を進め、心筋梗塞や脳梗塞の原因になります。

# 診断の目安（空腹時採血）
- LDLコレステロール 140mg/dL以上：高LDLコレステロール血症
- HDLコレステロール 40mg/dL未満：低HDLコレステロール血症
- トリグリセライド 150mg/dL以上（空腹時）：高トリグリセライド血症
- non-HDLコレステロール 170mg/dL以上：高non-HDLコレステロール血症
これらはスクリーニングのための基準であり、治療の必要性や目標値は、年齢、喫煙、高血圧、糖尿病などの他の危険因子を合わせて医師が判断します。

# 生活習慣の改善
飽和脂肪酸（脂身の多い肉、バターなど）を控え、魚や大豆製品、野菜、海藻、きのこを取り入れた食事が勧められます。適度な有酸素運動、禁煙、適正体重の維持も重要です。
