# 糖尿病とは
糖尿病は、インスリンの作用が不足することで血糖値が慢性的に高くなる病気です。日本の糖尿病の大部分は2型糖尿病で、遺伝的な要因に、食べ過ぎ、運動不足、肥満などの生活習慣が加わって発症します。1型糖尿病は、主に自己免疫によって膵臓のインスリンを作る細胞が壊れることで起こり、生活習慣とは関係なく発症します。

# 診断に用いる検査
日本糖尿病学会の基準では、空腹時血糖値126mg/dL以上、75g経口ブドウ糖負荷試験の2時間値200mg/dL以上、随時血糖値200mg/dL以上のいずれかを「糖尿病型」とし、HbA1c 6.5%以上も糖尿病型と判定します。診断は、これらの検査結果を組み合わせて医師が行います。

# HbA1cとは
HbA1c（ヘモグロビンエーワンシー）は、赤血球中のヘモグロビンにブドウ糖が結合した割合で、過去1〜2か月の平均的な血糖の状態を反映します。合併症を予防するための血糖コントロール目標として、一般的にHbA1c 7.0%未満が用いられますが、年齢や低血糖のリスクなどに応じて個別に設定されます。

# 合併症
高血糖が続くと、網膜症、腎症、神経障害の「三大合併症」のほか、心筋梗塞や脳梗塞などの動脈硬化性疾患のリスクが高まります。定期的な眼科受診や尿検査が勧められます。

# 治療の基本
食事療法と運動療法が治療の基本で、必要に応じて薬物療法を行います。治療薬の種類や量は、血糖値や合併症の状態を見て医師が決めます。低血糖（冷や汗、手の震え、動悸など）が起きた場合の対応は、あらかじめ医師や薬剤師に確認しておくことが大切です。
